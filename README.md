# QuickUse (Fabric 1.21.4)

Сборка: нужен JDK 21.
  gradlew build      (если нет gradlew — сгенерируйте шаблон на https://fabricmc.net/develop
                      для 1.21.4 / Yarn и скопируйте в него папку src + gradle.properties)
Готовый jar: build/libs/quickuse-1.0.0.jar -> в папку mods (нужен Fabric API).

Использование: Delete — меню; добавляете строки (предмет, клавиша, название).
Конфиг: config/quickuse.json
